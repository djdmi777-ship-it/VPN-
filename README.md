# Свой VPN на арендованном сервере (WireGuard)

Простая версия: один сервер, один или несколько клиентов. Платить не нужно —
всё бесплатное и опенсорсное, используется уже арендованный сервер.

## Шаг 1. Настройка сервера

1. Подключись к серверу по SSH:
   ```
   ssh root@ВАШ_IP_СЕРВЕРА
   ```
2. Скопируй на сервер `install-server.sh` и `add-client.sh` (например через `scp`
   с этого компьютера, или просто создай файлы на сервере и вставь содержимое).
3. Сделай скрипты исполняемыми и запусти установку:
   ```
   chmod +x install-server.sh add-client.sh
   sudo ./install-server.sh
   ```
   Скрипт сам поставит WireGuard, сгенерирует ключи сервера и запустит сервис.

## Шаг 2. Добавление своего компьютера как клиента

На сервере:
```
sudo ./add-client.sh mylaptop
```
Скрипт создаст файл `/etc/wireguard/clients/mylaptop.conf` и покажет QR-код
(пригодится для телефона).

Скопируй конфиг к себе на компьютер:
```
scp root@ВАШ_IP_СЕРВЕРА:/etc/wireguard/clients/mylaptop.conf .
```

## Важно: используем AmneziaWG, а не ванильный WireGuard

Обычный WireGuard оказался заблокирован по DPI-паттерну у провайдера (проверено:
не работал ни через Wi-Fi, ни через мобильный интернет, при этом сервер честно
отправлял ответные пакеты — они просто не доходили). Поэтому реально используется
`install-amnezia-server.sh` / `add-amnezia-client.sh` — это WireGuard-совместимый
протокол с обфускацией трафика, который не распознаётся как VPN по паттерну
пакетов. `install-server.sh` / `add-client.sh` (ванильный WireGuard) остались в
проекте как запасной вариант — вдруг где-то DPI не режет и хочется меньше
оверхеда.

Сервер AmneziaWG работает на порту 51821/UDP, ключи и параметры обфускации
(Jc/Jmin/Jmax/S1/S2/H1-H4) лежат в `/etc/amnezia/amneziawg/awg0.conf`.

## Шаг 3. Установка клиента на компьютер

1. Скачай официальный клиент AmneziaWG для Windows:
   https://github.com/amnezia-vpn/amneziawg-windows-client/releases/latest
   (файл `amneziawg-amd64-2.0.1.msi` для обычного 64-битного Windows 10/11).
   Обычный WireGuard-клиент с wireguard.com НЕ подойдёт — там другой протокол.
2. Установи `.msi`, запусти AmneziaWG.
3. Импортируй `pc.conf` из папки `client-toggle/` (кнопка "Import tunnel(s) from file").
4. Нажимай Activate/Deactivate в приложении — это и есть кнопка включения.

## Шаг 3 (альтернатива). Кастомная кнопка на Windows

В папке `client-toggle/` лежат `vpn-on.bat` и `vpn-off.bat` (уже настроены на
AmneziaWG и файл `pc.conf`).

1. Убедись, что `pc.conf` лежит в той же папке `client-toggle/`.
2. Двойной клик по `vpn-on.bat` — включает VPN (спросит права администратора).
3. Двойной клик по `vpn-off.bat` — выключает VPN.
4. Можно закинуть оба файла ярлыками на рабочий стол.

## Телефон

На телефоне тоже используется приложение **AmneziaWG** (не обычный WireGuard) —
конфиг `mylaptop_amnezia.conf` / QR `mylaptop_amnezia_qr.png` в `client-toggle/`.

## Что дальше (когда понадобится)

- Добавить ещё один сервер в другой стране (та же схема install-amnezia-server.sh
  на новом VPS) и просто переключаться между `.conf`-профилями в клиенте.
- Позже можно надстроить entry+exit схему для сохранения одного внешнего IP —
  тот вариант, который обсуждали, но посложнее.
